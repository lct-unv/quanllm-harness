# QuanLLM Harness v0.1.4

## 中文

`v0.1.4` 集中修复推理恢复管线中的定位、收敛和交付问题，并用 10 个定向用例进行了真实网关验证。

主要变化：

- 结构化断言提取可恢复有效字段，协议失败可生成受原问题约束的降级结果。
- 工具 JSON 参数可修复或退化为无工具路径，重复工具失败具有独立预算。
- 候选综合和修复不得回退到已被否定的状态；综合失败时保留更好的已验证候选。
- 新增可审计的确定性门禁，覆盖带标量和纯文本矩阵、复投影算符、模平方比、逆矩阵、本征谱/本征对、顺序态变换与最终量子态。
- 模型修复不收敛时，可对能由输入精确推出的矩阵/谱/状态进行显式回写，同时保留 `degraded_delivery` 与基础设施错误记录。
- 主求解器失败时自动切换独立求解器；双模型超时时，可对可确定的复投影问题交付精确本地降级答案。
- 新增 10 例复现运行器和对应回归测试。
- 修复 REST 同步回答端点在事件循环关闭时的偶发线程池死锁。

安装或升级：

```bash
python -m pip install --upgrade "quanllm-harness==0.1.4"
```

本版本只发布一个 Python wheel (`.whl`) 和一个源码包 (`.tar.gz`)。

## English

`v0.1.4` fixes localization, convergence, and delivery failures in the reasoning/recovery
pipeline, validated against ten targeted cases through the real gateway.

Highlights:

- Structured claim extraction now salvages valid fields and uses source-constrained fallbacks;
  malformed tool JSON can be repaired or downgraded to a tool-free path.
- Candidate synthesis and repair cannot silently restore an invalidated state, and synthesis
  failures preserve the stronger verified candidate.
- Added auditable deterministic gates for scaled and plain-text matrices, complex projectors and
  norm ratios, inverse matrices, eigenspectra/eigenpairs, ordered state transformations, and final
  quantum states.
- When model repair does not converge, locally provable matrices, spectra, and states are written
  back explicitly while retaining `degraded_delivery` and infrastructure diagnostics.
- A failed primary solver now falls back to the independent solver; if both time out, recognized
  complex-projection tasks can still deliver an exact local fallback answer.
- Added a ten-case reproduction runner and regression tests for all failures found during
  real-gateway validation.
- Removed an intermittent REST shutdown deadlock by keeping synchronous answer execution out of
  the event loop's default executor.

Install or upgrade:

```bash
python -m pip install --upgrade "quanllm-harness==0.1.4"
```

This release contains exactly two assets: one Python wheel (`.whl`) and one source distribution
(`.tar.gz`).
