# QuanLLM Harness v0.1.1

## 中文

`v0.1.1` 是一次配置隐私与发行物防回归更新。

主要变化：

- 固定网关改为在运行时构造，完整端点不再以明文存入源码、文档、测试、wheel 或源码包。
- 用户仍无需配置网关，CLI、Web UI 与 REST API 继续共享同一固定目标。
- 发行物校验器新增内容扫描；若完整端点重新出现在 wheel 或源码包中，CI 将直接失败。
- PyPI 徽章缓存键更新至本版本。

这项处理用于避免静态明文泄露，但不把客户端必须在运行时解析的目标地址误称为秘密。

安装或升级：

```bash
python -m pip install --upgrade quanllm-harness
```

本版本只发布 Python wheel (`.whl`) 和源码包 (`.tar.gz`) 两个资产。

## English

`v0.1.1` is a configuration-privacy and release-regression update.

Changes:

- The fixed managed gateway is now constructed at runtime; its complete endpoint is no longer
  stored in plaintext in source, documentation, tests, wheels, or source distributions.
- Users still do not configure the gateway, and the CLI, Web UI, and REST API continue to share
  the same fixed destination.
- Release validation now scans archive contents and fails CI if the complete endpoint reappears in
  either distribution.
- PyPI badge cache keys now target this release.

This avoids static plaintext disclosure without pretending that a destination resolved by a
distributed client at runtime can be a secret.

Install or upgrade:

```bash
python -m pip install --upgrade quanllm-harness
```

This release contains exactly two assets: one Python wheel (`.whl`) and one source distribution
(`.tar.gz`).
