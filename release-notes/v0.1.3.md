# QuanLLM Harness v0.1.3

## 中文

`v0.1.3` 将四阶段插件平台完整集成进 `quanllm-harness` 主发行包，同时加强了多小问量子力学题的证据绑定、标准结果核验和 REST 安全默认值。插件 API 不作为独立 SDK 发布。

主要变化：

- 在主包内新增稳定的 Plugin Manifest、Context、配置和生命周期契约。
- 支持 Tool、Verifier、Provider、Event 和 Service 扩展点，以及显式插件依赖。
- 插件默认禁用；未启用入口不导入 Python 模块。主机校验 API/版本、权限、依赖和可选 SHA-256 信任摘要。
- 子进程 Tool 采用无 shell 的 JSON 协议，具有超时、流式输出硬上限和收窄环境变量；文档明确区分协议隔离与 OS 沙箱。
- Tool Evidence 记录插件名、版本、摘要和执行模式；插件 Verifier 可报告问题，但不能自行授予 `verified`。
- 新增 `quanllm-harness plugins list/inspect/doctor/validate/enable/disable` 以及 REST `GET /api/v1/plugins`。
- 改进多小问要求和断言提取、工具调用语义审查与证据覆盖检查，并加强泡利矩阵、本征对、边界条件和密度矩阵等标准结果的确定性核验。
- REST 回答接口在未配置服务器令牌时默认拒绝请求，仅可通过显式的本地不安全选项关闭认证，令牌使用常量时间比较。
- 提供 Windows `install.ps1`，对 pycommute 源码执行 SHA-256 校验、MSVC 兼容处理和运行时自检。

安装或升级：

```bash
python -m pip install --upgrade "quanllm-harness==0.1.3"
```

本版本只发布一个 Python wheel (`.whl`) 和一个源码包 (`.tar.gz`)。

## English

`v0.1.3` integrates the complete four-stage plugin platform into the main
`quanllm-harness` distribution while strengthening evidence binding for multi-part quantum
problems, deterministic standard-result checks, and secure REST defaults. The plugin API is not
published as a separate SDK.

Highlights:

- Added stable Plugin Manifest, Context, configuration, and lifecycle contracts inside the main
  package.
- Added Tool, Verifier, Provider, Event, and Service extension points with explicit plugin
  dependencies.
- Plugins are disabled by default, and disabled entry points are not imported. The host validates
  API/host versions, permissions, dependencies, and optional trusted SHA-256 digests.
- Subprocess Tools use a shell-free JSON protocol with deadlines, a streaming output hard limit,
  and a reduced environment. Documentation clearly distinguishes protocol isolation from an OS
  sandbox.
- Tool Evidence records plugin name, version, digest, and execution mode. Plugin verifiers may
  report findings but cannot grant `verified` status.
- Added `quanllm-harness plugins list/inspect/doctor/validate/enable/disable` and REST
  `GET /api/v1/plugins`.
- Improved multi-part requirement and claim extraction, semantic tool-call review, evidence
  coverage, and deterministic checks for common Pauli, eigenpair, boundary-condition, and
  density-matrix results.
- REST answer endpoints now fail closed without a server token. Disabling authentication requires
  an explicit local insecure option, and configured tokens use constant-time comparison.
- Added a Windows `install.ps1` flow with pycommute source digest verification, MSVC compatibility
  handling, and runtime self-checks.

Install or upgrade:

```bash
python -m pip install --upgrade "quanllm-harness==0.1.3"
```

This release contains exactly two assets: one Python wheel (`.whl`) and one source distribution
(`.tar.gz`).
