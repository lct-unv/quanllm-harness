# QuanLLM Harness v0.1.5

## 中文

`v0.1.5` 将量子力学教学能力从通用 Harness 核心拆分为随 wheel 发行、默认关闭的官方
`quanllm-qm-teaching` 领域插件，并补齐领域提示词、验证和恢复所需的插件扩展点。

主要变化：

- 通用核心只负责编排、状态机、运行记录以及通用符号、矩阵和数值能力；量子教学提示词、
  标准结果、确定性验证、恢复策略和专用工具归属官方领域插件。
- 插件 API 新增 Prompt Contributor 和 Domain Strategy，可贡献分阶段提示词、候选门禁、
  受限修复指令、确定性降级答案、原子候选改写和交付前终结，但最终状态仍由核心裁决。
- `quanllm-qm-teaching` 随 Harness wheel 安装并可被源码运行和安装环境一致发现，默认不激活；
  启用后注册一个领域策略、一个提示词贡献者、一个确定性验证器和十个命名空间工具。
- QuTiP、pycommute 和 OpenFermion 移入 `qm-teaching` 可选依赖，通用安装不再强制携带量子后端。
- 插件验证器异常现在会留下基础设施问题并触发诚实的降级交付，不能复用先前的成功状态。
- 对复投影与顺序幺正变换引入原子恢复：重新计算并整体替换相关矩阵、状态、范数和行列式，
  防止候选综合重新引入已经失效的旧状态。
- 在启用插件后重新验证 10 个推理/恢复用例；所有最终答案均通过独立确定性检查，真实 provider
  或工具超时保留为 `degraded_delivery`，不再伪报验证成功。

安装或升级核心：

```bash
python -m pip install --upgrade "quanllm-harness==0.1.5"
```

安装量子教学可选后端并启用官方插件：

```bash
python -m pip install --upgrade "quanllm-harness[qm-teaching]==0.1.5"
quanllm-harness plugins enable quanllm-qm-teaching
```

本版本只发布一个 Python wheel (`.whl`) 和一个源码包 (`.tar.gz`)。

## English

`v0.1.5` moves quantum-mechanics teaching behavior out of the generic Harness core and into the
bundled, opt-in `quanllm-qm-teaching` domain plugin. It also completes the plugin extension surface
required for domain prompts, verification, and recovery.

Highlights:

- The generic core now owns orchestration, status transitions, run records, and generic symbolic,
  matrix, and numerical capabilities. Quantum teaching prompts, standard results, deterministic
  verification, recovery policy, and specialized tools belong to the official domain plugin.
- The plugin API adds Prompt Contributors and Domain Strategies for stage-aware prompts, candidate
  gates, bounded repair instructions, deterministic fallbacks, atomic candidate rewrites, and
  delivery-time finalization. The core remains the sole authority for final run status.
- `quanllm-qm-teaching` ships in the Harness wheel and is discovered consistently from source and
  installed distributions, but remains disabled by default. Enabling it registers one domain
  strategy, one prompt contributor, one deterministic verifier, and ten namespaced tools.
- QuTiP, pycommute, and OpenFermion move to the `qm-teaching` optional dependency group, keeping the
  default installation domain-neutral.
- Plugin-verifier exceptions now create infrastructure findings and force honest degraded delivery
  instead of reusing a previous successful status.
- Atomic recovery for complex projections and ordered unitary chains recomputes and replaces the
  complete dependent set of matrices, states, norms, and determinants, preventing synthesis from
  restoring invalidated state.
- All ten reasoning/recovery reproductions were revalidated with the plugin active. Every delivered
  answer passed independent deterministic checks; real provider or tool timeouts remain visible as
  `degraded_delivery` instead of false verification.

Install or upgrade the core:

```bash
python -m pip install --upgrade "quanllm-harness==0.1.5"
```

Install the optional quantum-teaching backends and enable the official plugin:

```bash
python -m pip install --upgrade "quanllm-harness[qm-teaching]==0.1.5"
quanllm-harness plugins enable quanllm-qm-teaching
```

This release contains exactly two assets: one Python wheel (`.whl`) and one source distribution
(`.tar.gz`).
