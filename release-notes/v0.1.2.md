# QuanLLM Harness v0.1.2

## 中文

`v0.1.2` 将项目 README 完整改为中英双语，并将同一份双语说明正式发布到 PyPI。

主要变化：

- README 现在包含内容对等的完整中文与 English 章节，而不只是双语简介。
- 安装、CLI、Web UI、REST API、受控 Agent 流程、量子后端、工程结构、开发验证、贡献者和许可证均提供英文对应内容。
- PyPI 版本徽章改为精确的静态版本徽章，避免新版本刚发布时短暂显示旧缓存。
- 原有运行逻辑、固定网关构造、工具后端和接口协议保持不变。

安装或升级：

```bash
python -m pip install --upgrade quanllm-harness
```

本版本只发布 Python wheel (`.whl`) 和源码包 (`.tar.gz`) 两个资产。

## English

`v0.1.2` makes the project README fully bilingual and publishes the same Chinese-English
documentation to PyPI.

Changes:

- The README now contains complete, content-equivalent Chinese and English sections instead of a
  bilingual introduction only.
- Installation, CLI, Web UI, REST API, the controlled Agent workflow, quantum backends, project
  structure, development verification, contributors, and licensing all have English counterparts.
- The PyPI release badge now uses an exact static version, preventing a newly published release
  from temporarily displaying stale cached version data.
- Runtime behavior, fixed gateway construction, tool backends, and interface protocols are
  unchanged.

Install or upgrade:

```bash
python -m pip install --upgrade quanllm-harness
```

This release contains exactly two assets: one Python wheel (`.whl`) and one source distribution
(`.tar.gz`).
