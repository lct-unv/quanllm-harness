# QuanLLM Harness v0.1.0

## 中文

`v0.1.0` 是 QuanLLM Harness 的首个公开版本。它将 QuanLLM-v2.0-qm 的求解、工具调用、逐断言核验、定向修复与最终交付组织为可维护的受控 Agent 工程。

主要内容：

- 隔离的双 Solver、综合、审核、独立裁决与有界修复流程。
- 共享同一 Harness 服务的会话 CLI、Web UI 和 REST/SSE API。
- SymPy、QuTiP、pycommute、OpenFermion 与高精度数值后端。
- 结构化量子算符代数，以及工具调用前的语义忠实性审查。
- 原始思维过程分 Agent 展示、实时运行时间与可滚动执行面板。
- 普通安装即包含 CLI、Web/REST 和全部量子后端，无需选择 extras。
- 项目以 MIT License 开源。

安装：

```bash
python -m pip install quanllm-harness
```

本版本只发布 Python wheel (`.whl`) 和源码包 (`.tar.gz`) 两个资产。

## English

`v0.1.0` is the first public release of QuanLLM Harness. It packages solving, deterministic tool
use, claim-level verification, targeted repair, and delivery for QuanLLM-v2.0-qm as a maintainable
controlled-agent system.

Highlights:

- Isolated dual solvers, synthesis, review, independent adjudication, and bounded repair.
- A conversational CLI, Web UI, and REST/SSE API backed by the same Harness service.
- SymPy, QuTiP, pycommute, OpenFermion, and high-precision numerical backends.
- Structured quantum-operator algebra and semantic fidelity review before every tool call.
- Per-Agent raw reasoning views, live elapsed time, and a fixed-height scrollable execution panel.
- One complete default installation containing CLI, Web/REST, and every quantum backend.
- Source code released under the MIT License.

Install:

```bash
python -m pip install quanllm-harness
```

This release contains exactly two assets: a Python wheel (`.whl`) and a source distribution
(`.tar.gz`).
